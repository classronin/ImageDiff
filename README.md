直接拖入两张图片到窗口即可加载。


- 鼠标滚动缩放图像。
- 按住图像移动位置。
- 按住分割线拖左右移动。
- 按 Home 键，重置视图。
- 按 Space 键，圆线。
- 按 + / - 键，圆线缩放。
- ESC 键，退出窗口。
